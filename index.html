Threads Analyzer / Social Post Engagement Analytics Platform

Enter a public Threads account and get an engagement report on its recent posts: overview metrics, Top 5 posts, posting-time heatmap, high/medium/low engagement group comparison, and LLM strategy suggestions. It extends my QSearch social-media analysis into a live web app.

My role Solo project | full-stack development, analytics pipeline, LLM output checking, and testing, built with Claude Code
  • Analytics: engagement mean and median, IQR outlier flags, Spearman correlation between length and engagement, and jieba + TF-IDF features for high/medium/low engagement groups split by score tertiles.
  • LLM checking: every Groq suggestion must cite the data path of each number; code verifies each value and metric name and falls back to rule templates when a suggestion fails.
  • Architecture: Next.js on Vercel, Supabase Auth and PostgreSQL with Row Level Security, and a Python Playwright worker triggered through GitHub Actions; supports multi-account comparison and Excel/CSV/JSON export.
